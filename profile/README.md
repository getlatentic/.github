# Latentic AI

Latentic AI explores **harness engineering for AI agents**: the systems around models that determine how agents act, use tools, retain state, acquire capabilities, and interact with software.

The work is applied to **AI in education**, for teachers and learners, as well as general-purpose agent systems. Reusable infrastructure and components are published independently.

## Harnesses

| **Project**                                                   |                                                                                                            |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [agent-harness](https://github.com/getlatentic/agent-harness) | Drive Claude Code, Codex, OpenCode, and OpenAI-compatible agents from Rust through a unified event stream. |
| [viva](https://github.com/getlatentic/viva)                   | Persistent, self-extending agents in Common Lisp.                                                          |
